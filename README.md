# 🍰 Meylicious - Artisanal Desserts & Basque Burnt Cheesecake

Website resmi untuk **Meylicious**, toko kue dan dessert artisanal premium. Spesialisasi dalam Basque Burnt Cheesecake lumer, Mascarpone Tiramisu, Fudgy Brownies, Choux Pastry, dan Gift Hampers.

## ✨ Fitur Website
- **Hero & Promo Banner:** Penawaran spesial dan informasi pengiriman.
- **Katalog Menu Interaktif:** Filter kategori produk (All, Cheesecake, Tiramisu, Brownies, Pastry, Hampers).
- **Detail Produk & Modal:** Informasi lengkap varian, bahan, dan deskripsi produk.
- **Keranjang Belanja (Cart) & Checkout:** Perhitungan otomatis, voucher diskon, dan opsi pengiriman.
- **Pemesanan Terintegrasi:** Checkout langsung mengirimkan rincian pesanan ke WhatsApp dengan format rapi.
- **Desain Responsif:** Tampilan optimal di smartphone, tablet, maupun desktop dengan gaya modern dan elegan.

## 🛠️ Teknologi yang Digunakan
- **HTML5**
- **CSS3** (Custom styling, responsive grid & flexbox, animasi halus)
- **JavaScript (Vanilla ES6+)** (Manajemen state keranjang, filter produk, modal, kalkulasi diskon)
- **Font Awesome & Google Fonts**

## 🚀 Cara Menjalankan
Buka file `index.html` langsung di browser Anda, atau gunakan live server local:
```bash
python -m http.server 8000
```
Buka `http://localhost:8000` pada browser.
